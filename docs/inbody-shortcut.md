# 인바디 → 아이폰 단축어로 자동 기록 (아주 자세히)

헬스장에서 인바디를 재면 아이폰 **건강(Apple Health)** 앱에 체중·체지방률·근육량이
쌓입니다. 아이폰 기본 **단축어** 앱이 하루 한 번 그 값을 깃허브에 올리면, 훈련일지
오늘 탭 컨디션이 자동으로 채워집니다. **인바디 비밀번호는 쓰지 않습니다.**

처음이라도 당황하지 않게 **3단계**로 나눴습니다.
- **1단계**: 체중 하나만 올려서 "되는지" 먼저 확인 (동작 5개)
- **2단계**: 체지방률·근육량 추가
- **3단계**: 매일 자동 실행

> 동작 이름은 아이폰 버전/언어에 따라 조금씩 다릅니다. 한글 이름과 영어 이름을 같이
> 적어 두었습니다. 화면에서 **검색창에 쳐서** 찾으면 됩니다. 어느 한 단계에서 화면이
> 다르면, 그 화면을 캡처해서 보여주시면 거기에 맞춰 알려드립니다.

---

## 준비물: 깃허브 토큰

단축어가 깃허브에 글을 쓰려면 "토큰"이라는 열쇠가 필요합니다. 훈련일지 **설정 탭에서
입력했던 그 토큰**과 같은 것을 씁니다. 적어둔 게 없으면 새로 만들면 됩니다(옛것도 계속
작동):

1. 사파리에서 열기 → https://github.com/settings/tokens/new?scopes=repo
2. **Note** 칸: `inbody-shortcut` (아무거나)
3. **Expiration**: `No expiration`(만료 없음) 또는 길게
4. **Select scopes**에서 **repo** 체크 (이미 체크돼 있으면 그대로)
5. 맨 아래 **Generate token** → 나온 `ghp_...` 값을 **복사** (이 화면 벗어나면 다시 못 봄)

이 토큰은 단축어 안에만 붙여넣고, 남에게 보여주지 마세요.

## 1단계 — 체중만 먼저 (동작 5개)

단축어 앱 → 오른쪽 위 **+** → **새로운 단축어**. 위쪽 이름을 `인바디 올리기`로 바꿉니다.
아래 동작을 하나씩 추가합니다(가운데 **동작 추가** 또는 아래 검색창 이용).

### 동작 1 — 체중 꺼내기
- 검색: `건강 샘플` → **건강 샘플 찾기** (Find Health Samples)
- `다음에 대한 샘플 찾기`(Sample type)를 눌러 **체중**(Weight) 선택
- `정렬 기준`(Sort by) → **종료 날짜**(End Date), 순서 **최신순/내림차순**
- `제한`(Limit)을 켜고 **1개**

### 동작 2 — 숫자만 빼기
- 검색: `세부사항` → **건강 샘플의 세부사항 가져오기** (Get Details of Health Samples)
- 입력은 자동으로 동작 1의 "건강 샘플"이 됩니다
- 가져올 세부사항: **값**(Value)
- 이 동작 결과를 꾹 눌러 변수 이름을 **체중**으로 바꿔 두면 편합니다

### 동작 3 — 올릴 내용 만들기
- 검색: `텍스트` → **텍스트**(Text)
- 아래를 그대로 입력하되, `[체중]` 자리에는 키보드 위 파란 변수칩에서 **체중**을,
  `[날짜]` 자리에는 변수칩의 **현재 날짜**를 끼워 넣습니다:

  ```
  {"date":"[날짜]","weight":[체중]}
  ```

- 넣은 **현재 날짜** 칩을 한 번 탭 → **날짜 형식**(Date Format) → **사용자 지정**(Custom)
  → 형식에 `yyyy-MM-dd` 입력. (그래야 `2026-11-02` 모양이 됩니다)

### 동작 4 — Base64로 바꾸기
- 검색: `base64` → **텍스트 인코딩**(Base64 Encode / Encode)
- 입력은 동작 3의 텍스트
- `줄바꿈`(Line Breaks) 옵션이 보이면 **없음**(None)으로
- 결과 변수 이름을 **본문64**로 바꿉니다

### 동작 5 — 깃허브에 올리기
- 검색: `URL의 콘텐츠` → **URL의 콘텐츠 가져오기** (Get Contents of URL)
- URL 칸에 아래를 입력(끝의 `[날짜]`는 변수칩 **현재 날짜**, 형식 `yyyy-MM-dd`):

  ```
  https://api.github.com/repos/psw9715-debug/training/contents/config/inbody/[날짜].json
  ```

- 동작을 펼쳐(**▸ 더 보기**) 아래를 설정:
  - **방법**(Method): **PUT**
  - **헤더**(Headers) → **+** 두 번:
    - 키 `Authorization` / 값 `Bearer 여기에_복사한_토큰_붙여넣기`
    - 키 `Accept` / 값 `application/vnd.github+json`
  - **요청 본문**(Request Body): **JSON** 선택 → **+**로 항목 두 개:
    - `message` (텍스트) : `inbody`
    - `content` (텍스트) : 변수 **본문64**

### 돌려보기
오른쪽 위 **▶︎**(또는 아래 재생 버튼)을 눌러 실행합니다.
- 성공하면 저장소 `config/inbody/오늘날짜.json` 파일이 생깁니다. 훈련일지를 새로고침하면
  오늘 컨디션의 **체중**이 채워집니다.
- 아무 반응이 없으면, 동작 5 뒤에 **빠른 보기**(Quick Look) 동작을 하나 붙여 다시 실행해
  보세요. 깃허브가 돌려준 메시지가 그대로 보입니다:
  - `Bad credentials` → 토큰이 틀림(동작 5의 Authorization 값 확인)
  - `"content":{...}` 같은 게 보이면 → **성공**입니다
  - `422 ... already exists` → 오늘 파일이 이미 있는 것(괜찮음)

여기까지 되면 제일 어려운 고비는 넘긴 겁니다.

## 2단계 — 체지방률·근육량 추가

동작 1~2를 **복사**해서(동작을 꾹 눌러 복제) 두 벌 더 만들고, 종류만 바꿉니다:
- 한 벌: **체지방률**(Body Fat Percentage) → 변수 이름 **체지방률**
- 한 벌: **제지방량**(Lean Body Mass) → 변수 이름 **근육량**
  (목록에 "제지방량"이 없고 "근육량/골격근량"만 있으면 그걸 고르세요)

그리고 동작 3의 텍스트를 이렇게 바꿉니다(변수칩으로 끼워 넣기):

```
{"date":"[날짜]","weight":[체중],"pbf":[체지방률],"smm":[근육량]}
```

- 체지방률이 `0.34`처럼 소수로 나와도 괜찮습니다 — 앱이 알아서 34%로 바꿉니다.
- 체지방'량'(kg)은 체중×체지방률로 앱이 계산합니다.

다시 ▶︎ 로 실행 → 새로고침하면 체중·골격근량·체지방량이 모두 채워집니다.

## 3단계 — 매일 자동으로

단축어 앱 아래 **자동화**(Automation) 탭 → **+** → **개인 자동화**(일부 버전은 바로
"새로운 자동화") → **시각**(Time of Day):

- 시간: 보통 인바디를 재고 난 뒤. 매일 밤 10시쯤이 무난합니다.
- 반복: **매일**
- 다음 → **단축어 실행**(Run Shortcut) 동작 선택 → 아까 만든 **인바디 올리기** 고르기
- **실행 전 확인**(Ask Before Running)을 **끔** → 묻지 않고 바로 실행

이제 매일 그 시각에, 아이폰이 잠겨 있어도(인터넷만 되면) 건강 앱의 최신 측정이 저장소로
올라가고 앱이 자동으로 읽습니다. 측정 안 한 날은 전날 값이 다시 올라갈 수 있는데, 같은
값이면 앱이 중복으로 세지 않습니다.
