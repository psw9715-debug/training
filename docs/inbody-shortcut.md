# 인바디 → 아이폰 단축어로 자동 기록하기

헬스장에서 인바디를 재면 아이폰 **건강(Apple Health)** 앱에 체중·체지방률·근육량이
쌓입니다. 아이폰 기본 **단축어(Shortcuts)** 앱이 하루 한 번 그 값을 깃허브에 올리면,
훈련일지 오늘 탭 컨디션 칸이 자동으로 채워집니다. **인바디 비밀번호는 필요 없습니다.**

올리는 방식은 아주 단순합니다 — 하루에 **파일 하나**(`config/inbody/날짜.json`)를 새로
만들 뿐입니다. 앱이 그 폴더를 읽어서 합칩니다.

---

## 0. 먼저 켜 둘 것

1. **인바디 앱 → 설정 → Apple 건강 연동**을 켭니다. (측정값이 건강 앱으로 들어가야 합니다)
2. 깃허브 토큰 하나가 필요합니다. 훈련일지 **설정 탭에서 쓰던 그 토큰**과 같은 걸 씁니다.
   없으면 https://github.com/settings/tokens/new?scopes=repo 에서 classic 토큰(`repo` 권한)을 만듭니다.
   이 토큰은 단축어 안에만 넣고, 남에게 보여주지 마세요.

---

## 1. 단축어 만들기 (한 번만)

단축어 앱 → 오른쪽 위 **+** → 아래 동작들을 순서대로 추가합니다.
(동작 검색창에 굵은 글씨를 쳐서 찾으면 됩니다)

### (1) 값 꺼내오기 — 건강에서 최근 측정 3개

**건강 샘플 찾기**(Find Health Samples) 동작을 **세 번** 넣습니다. 각각:

| 샘플 형식 | 정렬 | 개수 |
| --- | --- | --- |
| **체중**(Weight) | 종료 날짜 · 최신순 | 1개 |
| **체지방률**(Body Fat Percentage) | 종료 날짜 · 최신순 | 1개 |
| **제지방량**(Lean Body Mass) | 종료 날짜 · 최신순 | 1개 |

각 "건강 샘플 찾기" 바로 뒤에 **건강 샘플의 세부사항 가져오기**(Get Details of Health Samples)
→ **값**(Value) 을 넣어, 숫자만 빼냅니다. 나온 결과의 이름을 각각
`체중`, `체지방률`, `제지방량` 으로 바꿔 두면(동작을 꾹 눌러 "이름 변경") 다음 단계가 편합니다.

> 인바디 기기에 따라 제지방량 대신 **골격근량**만 건강에 들어갈 수도 있습니다. 그러면
> "제지방량" 자리에 건강에 실제로 있는 근육 관련 항목을 고르면 됩니다. 앱은 그 값을
> 근육량 칸에 넣습니다.

### (2) 오늘 날짜·시각 만들기

- **현재 날짜**(Current Date) 동작 추가.
- **텍스트**(Text) 동작 두 개:
  - 하나는 날짜 형식을 `yyyy-MM-dd` 로 (텍스트에 "현재 날짜"를 넣고 형식 지정) → 이름 `날짜`
  - 하나는 `HH:mm` 로 → 이름 `시각`

### (3) 올릴 내용(JSON) 만들기

**텍스트**(Text) 동작을 하나 넣고, 아래를 그대로 적되 대괄호 자리에는 위에서 만든
변수를 끼워 넣습니다(키보드 위 파란 변수칩으로 선택):

```
{"date":"[날짜]","time":"[시각]","weight":[체중],"pbf":[체지방률],"smm":[제지방량]}
```

이 텍스트를 **Base64로 인코딩**합니다: **텍스트 인코딩**(Encode Text / Base64 Encode) 동작 추가,
입력은 방금 만든 텍스트. → 이름 `본문64`

### (4) 깃허브에 파일 올리기

**URL** 동작:

```
https://api.github.com/repos/psw9715-debug/training/contents/config/inbody/[날짜]-[시각].json
```

(`[날짜]`·`[시각]` 은 변수. 시각의 `:` 때문에 파일명이 걱정되면 시각 대신 날짜만 써도
됩니다. 하루 한 번이면 `config/inbody/[날짜].json` 으로 충분합니다.)

**URL 내용 가져오기**(Get Contents of URL) 동작:

- **방식**(Method): `PUT`
- **헤더**(Headers) 두 개:
  - `Authorization` : `Bearer 토큰값` ← 여기에 깃허브 토큰을 붙여넣습니다
  - `Accept` : `application/vnd.github+json`
- **본문**(Request Body): **JSON** 선택, 항목 두 개:
  - `message` (텍스트) : `inbody [날짜]`
  - `content` (텍스트) : 변수 `본문64`

여기까지가 끝입니다. 오른쪽 위 ▶︎ 로 한 번 실행해 보세요. 성공하면 저장소
`config/inbody/` 폴더에 파일이 생기고, 훈련일지를 새로고침하면 그날 컨디션이 채워집니다.

> 실행했는데 아무 일도 없으면, "URL 내용 가져오기" 결과를 **빠른 보기**(Quick Look)로
> 띄워 보세요. 깃허브가 돌려준 오류 메시지가 그대로 보입니다. `Bad credentials` 면 토큰,
> `422` 면 같은 이름 파일이 이미 있는 것(그날 건 이미 올라간 것이라 괜찮습니다).

## 2. 매일 자동으로 돌리기

단축어 앱 → 아래 **자동화**(Automation) 탭 → **+** → **개인 자동화**(Personal Automation)
→ **시각**(Time of Day):

- 시간: 인바디를 보통 재고 난 뒤로. 매일 밤 10시쯤이 무난합니다.
- 반복: **매일**
- 다음 화면에서 방금 만든 단축어를 **동작으로 실행**하도록 고릅니다.
- **실행 전 확인**(Ask Before Running)을 **끕니다** → 묻지 않고 바로 돌아갑니다.

이제 매일 그 시각에 아이폰이 잠겨 있어도(인터넷만 되면) 건강 앱의 최신 측정이
저장소로 올라가고, 앱이 자동으로 읽습니다. 측정을 안 한 날은 전날 값이 그대로
다시 올라갈 수 있는데, 같은 값이면 앱이 중복으로 세지 않습니다.

---

## 왜 이렇게 하나요?

인바디 서버에 직접 로그인해서 받아오는 방법도 만들어 두었지만(`scripts/inbody_sync.py`),
한국 인바디 서버(v3)가 올바른 비밀번호도 `PW_FAIL` 로 거부합니다 — 비밀번호를 평문이
아닌 다른 방식으로 받는 것으로 보입니다. 남의 서버에 비밀번호를 여러 번 넣어 보는 건
하지 않는 게 맞아서, 이미 아이폰 안에 들어와 있는 건강 데이터를 쓰는 이 방법으로
돌렸습니다. 서버 방식은 나중에 인코딩이 확인되면 다시 켤 수 있습니다.
